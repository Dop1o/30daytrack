30-Дневный Челлендж Трекер
30-Дневный Челлендж Трекер — это простое и красивое веб-приложение для формирования полезных привычек и отслеживания прогресса в 30-дневных челленджах. Все данные хранятся локально в вашем браузере, ничего не отправляется на серверы.

📊 Управление трекерами
Создание трекеров с названием, категорией, описанием цели и цветом
15 цветов на выбор для персонализации
5 категорий: Здоровье, Обучение, Продуктивность, Осознанность, Другое

🚀 Как использовать
Создание трекера
Нажмите "Создать трекер" в навигации
Заполните форму:
Название челленджа (минимум 3 символа)
Категория из выпадающего списка
Цель на 30 дней (минимум 10 символов)
Цвет трекера (нажмите на кружок, чтобы раскрыть больше цветов)
Нажмите "Создать мой трекер!"

Отслеживание прогресса
Выберите трекер из списка "Мои трекеры"
В превью трекера нажимайте на ячейки дней, чтобы отметить выполнение
Прогресс будет автоматически обновляться
Статистика на главной странице меняется в реальном времени

Экспорт и шаринг
Скачать PDF: нажмите на зеленую кнопку под превью
Экспорт JSON
Копировать ссылку: поделитесь трекером с друзьями
Сохранить изменения: если нужно вручную сохранить прогресс

Управление трекерами
Открыть трекер: нажмите на карточку в списке
Поделиться: нажмите на иконку "Поделиться" в трекере
Удалить: нажмите на корзину (потребуется подтверждение)

🐛 Известные проблемы и решения
Часто задаваемые вопросы
Q: Куда сохраняются мои трекеры?
A: Все данные хранятся в localStorage вашего браузера. Они не передаются на серверы и доступны только вам.

Q: Могу ли я потерять данные?
A: Данные сохраняются пока вы не очистите localStorage браузера. Рекомендуется периодически скачивать PDF для архивации.

Q: Работает ли офлайн?
A: Да, после первого посещения приложение работает офлайн благодаря кэшированию.

Q: Сколько трекеров можно создать?
A: Ограничение — 50 трекеров для оптимальной производительности.
